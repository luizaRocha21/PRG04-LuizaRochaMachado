Ônibus universitário — rastreio em tempo real

O trajeto seguro da sua faculdade.

Este é o início do projeto UniBus: uma plataforma de transporte universitário com rastreio ao vivo, motoristas verificados e avisos instantâneos para estudantes.

Conhecer o projeto → Ir para o SandBox

📍 Rastreio ao vivo

Acompanhe a posição do ônibus em tempo real, direto do celular.

✅ Motoristas verificados

Todos os motoristas passam por validação da coordenação.

🔔 Avisos instantâneos

Notificações de atraso, troca de rota e chegada do ônibus.

Sobre esta etapa

Esta versão do projeto está sendo construída em HTML, CSS e JavaScript puros, agora com Bootstrap para grid e componentes.
